# 视觉参考与改版方向

## 已实现的页面

- 页面将 `figs/` 的留白、黑白结构和红黄点色组合为清晰的个人主页。正文围绕简洁的身份介绍、论文、经历和联系方式展开。
- 右侧主视觉把奶龙撑红伞过街原图分成斑马线背景、身体和雨伞图层，再重组为可拖动的场景。拖动时显露分层效果，点击雨伞触发雨纹波动，键盘可操作；角色不是另行绘制的卡通图。
- 左侧切换红色海岸、光影、漩涡和红海时，将下一幅原画裁成四条斜边切片，横向拖动控制接合程度。每张画沿用自己的裁切中心，姓名末词也从选中的画面取纹理。
- 页尾将黑白原片与拼贴按人物轮廓对齐。拖动接缝改变两张图的可见区域，让读者看清哪些像素换成了海面。滑块支持方向键、Home 和 End。
- 五张原 PNG 保持不变，网页用图及身体/雨伞图层的来源在 `figs/manifest.json` 追溯。
- Research / Projects 使用浏览器原生 `<details>` 展开项目主题、机构、时间与方法。用户关闭页脚动态按钮可暂停动效；系统 `prefers-reduced-motion` 设置仍优先生效。
- 手机和桌面采用适配式版面，重要资料保留静态 HTML，支持键盘焦点、图片替代文本和触摸操作。

以下保留原始视觉参考与设计依据。

## 建议的整体方向

以易读的学术主页为基础，加入有辨识度的超现实艺术气质。论文和经历有清晰的信息层级，图像负责视觉节奏。无需把五张图全部塞进首页。

第一版建议采用宽留白、非对称图文、少量细线、明显的字号层级；学术条目可以是简洁的纵向列表。不要把每一段都放入相同的圆角卡片。排版可使用有个性的标题字体与朴素的正文无衬线字体，避免为字体引入很重的运行依赖。

以下是根据图像拟定的起始色值，并非精确取样或已确定品牌规范：

| 用途 | 色值 |
| --- | --- |
| 背景 / 暖白 | `#F4F1E8` |
| 主文字 / 墨黑 | `#101114` |
| 强调 / 朱红 | `#D92D20` |
| 点缀 / 明黄 | `#F1CB2E` |
| 少量冷色 / 浅青 | `#B4F2F1` |

红、黄、青不必同时出现在每个区块。正文优先使用对比充分的黑白组合，链接与焦点状态既靠颜色也靠形状或下划线识别。

## 建议的信息顺序

1. 姓名、研究方向、简短身份介绍与联系入口。
2. Selected Publications，完整保留 Accepted / Submitted 状态。
3. Research / Projects，以具体工作解释研究兴趣。
4. Experience 与 Education，清楚标识未来入学。
5. 简短 About / Interests 与 Contact 收尾。

这是基于现有 CV 的起点。不要增加没有内容支撑的奖项、推荐语、团队、客户标识或空 News 栏目。

## 素材处理

- 原图留在 `figs/`；不要编辑、压缩覆盖或重命名它们。
- 实际网页素材放在 `assets/images/`；在 manifest 的 `derivatives` 中记录原画、斑马线背景与主体图层的对应关系。
- 使用 `srcset` / `sizes` 和显式宽高，按显示尺寸准备资源。首屏只优先加载主要图片，其余按需懒加载。
- 裁切后仍需看得见画面中的关键主体。手机端不要简单沿用桌面的裁切中心。
- 装饰图片使用空 `alt`，需要传递含义的图片给出简洁描述；不能把艺术图描述为论文结果。
- 动效支持页脚暂停和 `prefers-reduced-motion`；不做持续闪烁、自动播放音频或遮挡阅读的全屏效果。

## 第一版视觉验收

在约 390 px 手机宽度和 1440 px 桌面宽度检查排版、图像和导航。正文需清晰可读、无横向溢出，论文状态明确，键盘焦点可见，链接有效。持续修改时按此标准回归检查。
